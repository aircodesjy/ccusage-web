클라이언트 설정 방법

각 컴퓨터에서 Claude Code 사용량을 이 서버로 보내는 방법입니다.

서버 주소를 확인하는 중입니다…

사용자 ID와 이름은 모두 필수이며, 입력하면 아래 명령어에 채워집니다. 사용자 ID는 영문, 숫자와 . _ % + @ -만 쓸 수 있고, 한글 이름은 이름 칸에 입력하세요.

  1. Node.js 설치

    Node.js 20 이상이 필요합니다. 터미널에서 node -v로 확인하고, 없으면 nodejs.org에서 설치하세요. Claude Code만 설치된 컴퓨터에는 Node.js가 없을 수 있습니다.

  2. 한 줄 실행

    터미널(Windows는 PowerShell)에 붙여넣으면 설정 저장, 이 컴퓨터에 설치, 최근 7일 전송, 매일 자동 전송 등록까지 한 번에 끝납니다. 사용하는 컴퓨터마다 한 번씩 실행하세요.

    이 서버는 업로드 토큰이 필요합니다. 관리자에게 받은 토큰으로 YOUR_TOKEN을 바꾸세요.

    자동 전송은 매일 13:00에 macOS는 launchd, Linux는 cron, Windows는 작업 스케줄러로 실행됩니다. 시각은 --time 09:30으로 바꾸고, 자동 전송 없이 설치만 하려면 --no-schedule을 붙이세요(필요할 때 cc-usage send로 보냅니다).

    옵션 없이 setup까지만 입력하면 서버 주소, 사용자 ID, 이름, 자동 전송 시각을 하나씩 물어보는 방식으로 설정할 수도 있습니다.

설치 후 관리

cc-usage를 찾을 수 없다고 나오면 setup 마지막에 표시된 경로로 실행하세요. setup을 다시 실행하면 최신 버전으로 업데이트됩니다.

서버로 보내는 정보

사용자 ID, 이름, 머신 ID(OS 식별자의 해시), 호스트 이름, 그리고 기간 합계와 날짜별 토큰 수(입력·출력·캐시 생성·캐시 읽기)와 세션 수만 보냅니다. 비용, 프로젝트, 모델, 대화 내용은 보내지 않습니다. 마지막으로 보낸 내용은 ~/.config/cc-usage/last-upload.json에서 확인할 수 있습니다.
